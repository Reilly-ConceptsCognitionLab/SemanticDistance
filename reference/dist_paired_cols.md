# dist_paired_cols

Function takes dataframe cleaned using \`clean_paired_columns\`,
computes two metrics of semantic distance for each word pair arrayed in
Col1 vs. Col2

## Usage

``` r
dist_paired_cols(dat)
```

## Arguments

- dat:

  a dataframe prepped using \`clean\_\_paired_columns\` with word pairs
  arrayed in two columns

## Value

a dataframe
