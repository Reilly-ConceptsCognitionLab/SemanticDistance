# Glove Semantic Embeddings

Word embeddings (300 parameter dimensions, 59061 words). Each word is
one row.

## Usage

``` r
glowca_25
```

## Format

\## "glowca_25" A data frame with 59061 observations of 301 variables

- word:

  word characterized across embeddings

- Param_1:

  parameter number 1

- Param_300:

  parameter number 300
